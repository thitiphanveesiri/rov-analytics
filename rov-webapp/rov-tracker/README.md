# rov-tracker — ดึงตำแหน่งฮีโร่จากมินิแมพ → Heatmap

สคริปต์ Python ที่อ่านวิดีโอแมตช์ (อัดหน้าจอ/รีเพลย์ที่เห็นมินิแมพ) แล้วสร้าง `tracks.json`
ไปเปิดในหน้า **🔥 Heatmap** ของเว็บ รันบนเครื่องคุณ ไม่ใช่บน Vercel

## ติดตั้ง
```
pip install -r requirements.txt
```

## ใช้งาน 2 ขั้น

**1) ตรวจกรอบมินิแมพ + การผูกชื่อฮีโร่ (ทำก่อนทุกครั้ง)**
```
python track.py match.mp4 --minimap 15,55,210,250 --seed-time 5 \
  --our Nakroth,Murad,Krixi,Capheny,Alice \
  --enemy Airi,Raz,Tulen,Valhein,Mina --preview-only
```
- `--minimap x0,y0,x1,y1` คือกรอบมินิแมพเป็นพิกเซลในวิดีโอ (ครอบให้พอดี เป็นสี่เหลี่ยมจัตุรัส)
- `--our / --enemy` = ฮีโร่ฝั่งละ 5 ตัว เรียงตามลำดับ slot ในดราฟต์ของเว็บ ใช้ชื่อตามระบบ (ตรงกับชื่อไฟล์ใน `public/heroes`)
- `--seed-time` = วินาทีที่ฮีโร่กระจายกัน เห็นไอคอนชัด (ยิ่งเห็นครบ 10 ตัวยิ่งดี)
- เปิด `tracks_seed_preview.png` ดูว่าแต่ละวงถูกติดชื่อถูกไหม
  ถ้าผิด ให้ทำไฟล์ `seed.json` เช่น `{"our:0":[0.32,0.34]}` (ตำแหน่ง 0–1 ของฮีโร่ตัวนั้น) แล้วเพิ่ม `--seed-override seed.json`
  (`our:0` = slot แรกของทีมเรา, `enemy:2` = slot ที่ 3 ของศัตรู)

**2) รันทั้งเกม**
```
python track.py match.mp4 ...ตัวเลือกเดิม... --hz 2 --game-start 0 --out tracks.json
```
- `--game-start` = เวลาในเกม (วินาที) ที่ตรงกับวินาทีที่ 0 ของวิดีโอ ใช้แบ่งช่วง 0–4/4–8/8–12 นาทีให้ตรง
- `--hz 2` = ตรวจ 2 ครั้ง/วินาที (เพียงพอสำหรับ Heatmap) ; เกม 30 นาทีใช้เวลาไม่กี่นาที
- `--map-image clean.png` = ถ้ามีภาพมินิแมพสะอาด จะใช้เป็นพื้นหลังแทนภาพที่ระบบสร้างจากวิดีโอ
- ตอนจบจะพิมพ์ "ความครอบคลุม" ต่อฮีโร่ — ดูตัวเลขนี้ก่อนเชื่อ Heatmap

## อ่านผลให้ถูก (สำคัญ)
- ไอคอนที่ซ้อนทับกัน (ตอนปะทะกัน) และที่ติดขอบแผนที่ มักจับไม่ได้ ช่วงนั้นจะ **ว่าง** หรือถูก **ประมาณ** (conf 0.2)
  หน้า Heatmap ค่าเริ่มต้นใช้เฉพาะจุดที่ "เห็นจริง" และเตือนเมื่อเห็นจริงน้อยกว่า 50%
- ฮีโร่ที่ไม่เห็นตอนเฟรมเริ่มต้น ระบบจะผูกไอคอนที่ยังว่างให้แบบมั่นใจต่ำ — ถ้าฮีโร่ฝั่งเดียวกันหลายตัวไม่เห็นพร้อมกัน **อาจสลับชื่อกันได้**
  แก้ด้วยการเลือก `--seed-time` ที่เห็นครบ หรือใช้ `--seed-override`
- ไฟล์ต้นฉบับความละเอียดสูง (1080p) ให้ผลดีกว่าคลิปที่ย่อ/อัดซ้ำมาก
